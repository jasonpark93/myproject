# 릴스·쇼츠 자동 제작기

Claude에게 말로 시키면 릴스가 나와요. 두 가지 방식이 있어요.

| | **A. 모션그래픽 릴스** (얼굴 없이) | **B. 말하는 영상 편집** |
| --- | --- | --- |
| 화면 | 검정 배경 + 상단 형광 제목 + 움직이는 카드(체크리스트·큰 글씨·비교 막대·댓글 CTA…) + 자막 | 내 얼굴 영상 + 자막 + 펀치/슬로우 줌 |
| 내가 할 일 | Claude가 써 준 대본을 **음성 메모로 녹음**만 | 폰으로 **촬영** |
| Claude에게 | "○○ 주제로 릴스 만들어줘" → 대본 확인 → 녹음 → "녹음했어" | "편집해줘" |
| 참고 | 보내준 '클로드 영상 자동편집' 릴스와 같은 스타일 | 강의의 편집 지침을 검증·개선해서 적용 |

두 방식 모두 군말·NG·쉼 컷, 대본 기준 오타 없는 자막, 효과음(휙·띵·뽁), 음량 -14 LUFS, 1080x1920 완성본, 보고서까지 자동이에요.

- **돈:** 0원. 모든 처리를 내 컴퓨터에서 해요. API·유료 앱이 필요 없고, Claude 구독만 있으면 돼요.
- **시간:** 하루 15~20분.
  - A: 녹음 3분 + 확인·업로드 5분 (Claude가 대본 쓰고 만드는 동안 기다리기)
  - B: 촬영 5~10분 + 확인·업로드 5분
- **원본:** 녹음·영상은 내 컴퓨터에만 있어요. GitHub에는 올라가지 않아요.

## A. 모션그래픽 릴스: 이렇게 말하세요

1. **"청약통장 주제로 릴스 만들어줘"**
   - Claude가 대본과 장면(카드)을 쓰고, 컴퓨터 음성으로 미리보기를 만들어 보여줘요.
2. 대본이 마음에 들면 휴대폰 **음성 메모**로 읽어요.
   - 틀리면 2초 쉬고 그 문장 처음부터 다시 읽으면 돼요.
   - 파일 이름을 스토리 이름(예: `cheongyak-01.m4a`)으로 바꿔 `reels/inbox/`에 넣어요.
3. **"녹음했어"** → 내 목소리에 맞춰 카드가 움직이고 자막이 붙은 완성본이 `reels/out/`에 나와요.
4. 고칠 게 있으면 말로 요청해요. 예: "3번째 장면 문구 바꿔줘", "제목 더 짧게", "효과음 줄여줘"

- 대본·장면 작성 기준(Claude용): [STORY_GUIDE.md](STORY_GUIDE.md)
- 예시: `stories/example.json` (보내주신 릴스 구성을 그대로 옮긴 것) → `python reels/reel.py story example --tts`
- 배경음악: `reels/bgm/`에 음악 파일을 넣으면 목소리보다 작게 깔려요. 저작권 없는 곡은 YouTube 오디오 보관함에서 받으세요. 아니면 인스타에 올릴 때 앱에서 음악을 추가해도 돼요.
- 댓글 CTA("댓글에 '키워드' 남기면 자료 보내드려요")를 쓰려면 실제로 보낼 자료가 있어야 해요. 인스타 댓글 자동 DM은 ManyChat 같은 자동 응답 도구로 설정해요.

이 아래부터는 B(말하는 영상 편집) 설명이에요. 설치는 두 방식이 같아요.

---

## 1. 처음 한 번만: 설치

1. **Claude 데스크톱 앱**을 설치하고 로그인 → 왼쪽 위 **Code** 탭 → 이 저장소 폴더(`myproject`)를 열기.
   - 저장소가 아직 없으면 터미널에서 `git clone https://github.com/jasonpark93/myproject.git`
2. Claude에게 이렇게 말하기: **"reels 세팅해줘"**
   - Claude가 `python reels/reel.py doctor`로 점검하고, 빠진 것(ffmpeg, 파이썬 패키지)을 설치해 줘요.
   - 직접 하려면:
     - Mac: `brew install ffmpeg` → `python3 -m pip install -r reels/requirements.txt`
     - Windows: `winget install Gyan.FFmpeg` → 터미널 다시 열기 → `python -m pip install -r reels/requirements.txt`
3. 첫 편집 때 음성 인식 모델(약 1.6GB)을 한 번 내려받아요. 그다음부터는 바로 돼요.

> 앱 대신 터미널을 쓰고 싶으면, 저장소 폴더에서 `claude remote-control`을 실행하면 폰의 Claude 앱에서도 이어서 시킬 수 있어요.

## 2. 매일 루틴 (15~20분)

1. **촬영 (5~10분)** — 아래 '촬영 규칙'대로 한 번에 찍어요. 틀리면 2초 쉬고 그 문장을 처음부터 다시 말하면 돼요.
2. **옮기기 (1분)** — 영상을 `reels/inbox/` 폴더에 넣어요. 대본이 있으면 같은 이름의 `.txt`도 같이 넣어요.
3. **"편집해줘"** — Claude가 편집하고 보고서와 스냅샷 3장을 보여줘요.
4. **확인·수정 (2~5분)** — `reels/out/`의 완성본을 보고, 고칠 게 있으면 말로 요청해요. 고친 부분만 다시 만들어요.
5. **업로드 (2분)** — 같은 파일을 유튜브 쇼츠와 인스타 릴스에 올려요.

## 3. 촬영 규칙

| 규칙 | 이유 |
| --- | --- |
| 세로, **4K 30fps**로 찍기 | 115% 펀치 줌을 해도 선명해요. 1080p는 확대하면 흐려져요. |
| 아이폰은 **HDR 비디오 끄기** (설정 > 카메라 > 비디오 녹화) | HDR은 변환하면 색이 바래 보일 수 있어요. |
| 폰은 **눈높이**, 얼굴과 **50cm**, 렌즈를 보고 말하기 | 얼굴이 화면 위쪽 1/3에 오면 자막·제목과 안 겹쳐요. |
| 머리 위로 **손바닥 하나만큼** 여백 두기 | 첫 3초에 뜨는 훅 제목 자리예요. |
| 화면을 길게 눌러 **노출·초점 고정** | 밝기가 출렁이지 않아요. |
| 조용한 방, 창문 빛을 얼굴 정면으로 | 소리가 깨끗해야 자막 인식도 정확해요. |
| (추천) 2~3만 원대 **무선 핀마이크** | 화질보다 소리가 이탈률에 더 영향을 줘요. |
| 시작·끝에 **1초씩 가만히** | 첫마디·끝말이 잘리지 않아요. |
| 틀리면 **2초 멈추고 그 문장 처음부터** | 마지막 테이크만 자동으로 남겨요. |
| 첫 문장(훅)은 **2초 안에** 핵심을 말하기 | 시청자는 2초 안에 넘길지를 정해요. |
| 완성본 **20~45초** 목표 (원본 1분 이내) | 끝까지 보는 비율이 높아야 추천이 잘 돼요. |

## 4. Claude에게 이렇게 말하세요

- **편집 요청:** "편집해줘" / "inbox에 넣은 거 편집해줘" / "대본은 0107.txt야"
- **수정 요청:** 아래처럼 말하면 해당 부분만 다시 만들어요.

| 이렇게 말하면 | Claude가 하는 일 |
| --- | --- |
| "문장 사이 0.2초로" | `set 이름 gap=0.2` |
| "0:12 다시 살려줘" | 0:12 근처 잘린 곳 되살리기 (`keep 이름 0:12`) |
| "자막 20% 크게" | `set 이름 caption.size=1.2` |
| "'클라우드'→'클로드'" | `fix 이름 클라우드 클로드` |
| "강조색 민트로" | `set 이름 caption.highlight=민트` |
| "펀치 줌 3번만" | `set 이름 zoom.max_punch=3` |
| "줌 110%" | `set 이름 zoom.punch=1.10` |
| "효과음 볼륨 절반" | `set 이름 sfx.volume=0.5` (영상은 다시 안 만들고 소리만, 몇 초) |
| "효과음 빼줘" | `set 이름 sfx.enabled=false` |
| "세 번째 문장 지워줘" | `drop 이름 S3` |
| "제목 바꿔줘: ○○" | `title 이름 "○○"` |
| "제목 계속 보이게" | `set 이름 title.duration=0` |
| "앞으로도 계속 이렇게" | 같은 설정을 `--save`로 저장해서 다음 영상부터 기본값으로 써요 |

## 5. 편집 기준: 강의 내용을 그대로 따르지 않고 검증해서 정했어요

| 항목 | 강의 지침 | 이 편집기 | 근거 |
| --- | --- | --- | --- |
| 자막 위치 | 아래에서 30% | **아래에서 38%** | 인스타 릴스는 화면 아래 약 35%를 캡션·버튼이 덮어요. 유튜브 쇼츠는 아래 약 300px을 덮어요. |
| 자막 크기·폭 | 한 줄 12자 | 12자, **약 78px**, 오른쪽 버튼을 피해 살짝 왼쪽에 배치 | 쇼츠 권장 자막 크기는 60~75px, 공통 안전 영역은 900px 폭이에요. |
| 군말('음','어') 컷 | 받아쓰기에서 찾아 컷 | 받아쓰기 + **소리 에너지로 '인식 안 된 소리'까지** 컷 | Whisper는 군말·말더듬을 받아 적지 않고 빼는 경향이 있어요. |
| 컷 경계 | 단어 시간 기준 | **실제 소리 시작·끝에 맞추고 1/30초 격자** | 인식 시간은 0.1~0.2초씩 틀려요. 영상과 음성이 같은 지점에서 잘려야 싱크가 안 밀려요. |
| 펀치 줌 | 문장 시작에 | 문장 근처에 컷이 있으면 **컷 순간에 줌 전환**, 문장 안 점프컷엔 6% 크기 변화 | 확대·축소가 점프컷을 '카메라 전환'처럼 보이게 가려줘요. |
| 편집 속도 | 0.1~0.15초만 남김 | **0.15초** | 연구에 따르면 편집이 너무 빠르면 오히려 끝까지 보는 비율이 떨어져요. |
| 첫 화면 | 0.3초 안에 첫 말 | 0.1초 안에 첫 말 + **0초부터 자막** + (선택) 첫 3초 훅 제목 | 시청자 70%가 2초 안에 넘길지 정해요. 3초 유지율 80% 이상이 목표예요. |
| 음량 | 일정하게 | 잡음 제거 + 압축 + **-14 LUFS**, 피크 -1.5dB | 유튜브는 -14 LUFS 기준이고, 인스타·틱톡도 비슷하게 맞춰요. |
| 효과음 | 10초에 2~3개 | 10초에 최대 3개, 목소리보다 9~11dB 작게, 순간 최대치 제한 | 효과음이 많고 크면 싸구려처럼 느껴져요. |

## 6. 잘 되는 릴스를 따라 하고 싶을 때

참고할 릴스를 **폰에서 화면 녹화**해서 `reels/inbox/`에 넣고 "이 영상 분석해서 비슷하게 맞춰줘"라고 하세요.
Claude가 `ref` 명령으로 다음을 숫자로 재고, 장면 모음 이미지도 같이 보고 설정을 맞춰줘요.
- 컷·줌 리듬
- 자막 위치·크기·강조 비율
- 말 속도·쉼
- 음량

## 7. 폴더

| 폴더 | 내용 |
| --- | --- |
| `inbox/` | 촬영본을 넣는 곳 (GitHub에 안 올라감) |
| `out/` | 완성본 |
| `work/이름/` | 작업별 자료: `review.md`(편집 전 검토표), `report.md`(보고서), `snapshots/`(스냅샷 3장), `plan.json`(편집 계획) |
| `sfx/` | 내 효과음 파일 (선택) |
| `fonts/` | 자막 글꼴 Pretendard (SIL OFL 라이선스) |

## 8. 문제 해결

| 증상 | 해결 |
| --- | --- |
| "ffmpeg가 없습니다" | Mac은 `brew install ffmpeg`, Windows는 `winget install Gyan.FFmpeg` 후 터미널을 다시 열기 |
| 음성 인식 설치가 안 됨 | Vrew·CapCut에서 자막을 SRT로 내보내 같이 주세요. Claude가 `--srt`로 대신 처리해요. |
| 인식이 느림 | "빠르게 해줘" → `--model small` (정확도는 조금 떨어져요) |
| 색이 바래 보임 | 아이폰 HDR 비디오 끄고 촬영 |
| 자막 오타 | "'틀린말'→'바른말'" 한마디면 고쳐져요. 대본 txt를 같이 주면 대본 기준으로 자동 교정돼요. |
