# 내 효과음 쓰기 (선택)

이 폴더에 아래 이름으로 파일을 넣으면 자동 생성 효과음 대신 그 파일을 씁니다. (wav·mp3·m4a 가능)

| 파일 이름 | 쓰이는 곳 |
| --- | --- |
| `whoosh.wav` | 휙 — 펀치 줌이 들어갈 때 |
| `ding.wav` | 띵 — 숫자·키워드가 나올 때 |
| `pop.wav` | 뽁 — 전환(반전·결론·CTA) |

- 저작권 걱정 없는 효과음: YouTube 스튜디오 → 오디오 보관함 → 음향 효과.
- 크기는 자동으로 목소리보다 작게 맞춥니다. 지금 소리를 들어 보려면 `python reels/reel.py sounds` → `reels/sfx/preview/`.
- 이 폴더의 소리 파일은 GitHub에 올라가지 않습니다.
