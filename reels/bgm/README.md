# 배경음악 (선택)

모션그래픽 릴스(story)에 깔 음악 파일을 여기에 넣으세요 (mp3·m4a·wav). 첫 번째 파일을 목소리보다 약 21dB 작게 깔고 끝에서 줄입니다.

- 저작권 걱정 없는 곡: YouTube 스튜디오 → 오디오 보관함 → '저작자 표시 필요 없음'.
- 인스타그램은 올릴 때 앱에서 음악을 붙이는 편이 노출에 유리할 수 있어요. 그럴 땐 비워 두세요.
- 스토리마다 다르게 하려면 스토리 파일에 `"bgm": "경로"`(없애려면 `false`).
- 이 폴더의 음악 파일은 GitHub에 올라가지 않습니다.
